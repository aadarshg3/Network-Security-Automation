Steps to Set Up the Cache Clearing Script
Create the Script:

Open the terminal and create the script:

sh
nano /home/rahulverma/clear_cache.sh
Add the following content to the script:

sh
#!/bin/bash
LOG_FILE="/home/rahulverma/clear_cache.log"
echo "Attempting to clear caches..." >> $LOG_FILE
sudo sync
echo 3 | sudo tee /proc/sys/vm/drop_caches
echo "Cache cleared at $(date)" >> $LOG_FILE
Save and exit the editor (CTRL + X, then Y, and press ENTER).

Make the Script Executable:

sh
chmod +x /home/rahulverma/clear_cache.sh
Allow the Script to Run Without Password:

Edit the sudoers file:

sh
sudo visudo
Add the following line at the end of the file:

sh
rahulverma ALL=(ALL) NOPASSWD: /home/rahulverma/clear_cache.sh
Create a Cron Job:

Open the crontab editor:

sh
crontab -e
Add the following line to schedule the script to run every 2 minutes:

sh
*/2 * * * * /home/rahulverma/clear_cache.sh
Steps to Verify the Script is Running Automatically
Check the Script's Log File:

Monitor the log file to see if new entries are being added every 2 minutes:

sh
tail -f /home/rahulverma/clear_cache.log
Check Cron Logs:

Inspect the cron logs to see entries related to your script:

sh
sudo grep CRON /var/log/syslog
Check Cron Service Status:

Ensure the cron service is running:

sh
sudo systemctl status
