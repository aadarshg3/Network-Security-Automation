1. Set Up ngrok for Public Reachability
Install and start ngrok to expose your AWX server to the internet.

Run the command:

ngrok http awx service port (eg 30027)
Copy the public ngrok URL (e.g., https://abcd1234.ngrok-free.app).

2. Configure AWX to Allow External Triggers
Log in to AWX and create or use an existing job template (e.g., show ip int bri).

Generate an API token in AWX:

Go to Users > Your User > Tokens.

Create a new token and copy it.

3. Create a REST Message in ServiceNow
Go to System Web Services > Outbound > REST Message.

Create a new REST message:

Name: Trigger AWX Job Template

Endpoint: Use the ngrok URL (e.g., https://abcd1234.ngrok-free.app).

Authentication Type: Basic.

Username: Your AWX username or ansible.

Password: Your AWX password or API token.

Save the REST message.

4. Add a REST Method to Trigger the Job Template
Open the REST message and add a new method:

HTTP Method: POST

Endpoint: Append the AWX API endpoint:


/api/v2/job_templates/<job_template_id>/launch/
Replace <job_template_id> with the ID of your job template (e.g., 14).

Save the method.

5. Test the REST Method
Open the REST method and click Test.

Verify the response:

A 201 Created status indicates the job template was triggered successfully.

Check the AWX Jobs section to confirm the job executed.

6. Update the Playbook to Include a ServiceNow Trigger Message
Modify your playbook to include a task that confirms the playbook was triggered via ServiceNow:

yaml
Copy
- name: "03 - OUTPUT MESSAGE"
  debug:
    msg: "This playbook was triggered by servicenow"
