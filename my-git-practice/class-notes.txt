1) git init  --> creates a dir with name .git (multiple dir and files)
2) git status --> shows untracked files and on which branch you are
3) git commit -m "abc" --> used to make a commit and can give a valid message
4) git log ==> show all the logs
5) git branch -c "branch name"
6) git branch -a ==> to list all branch
7) git log --oneline --graph --all --decorate
